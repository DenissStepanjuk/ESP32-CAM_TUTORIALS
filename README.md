### ESP32-CAM 01: Захват кадра

В этом видео начинается серия уроков по работе с модулем **ESP32-CAM** — микроконтроллером ESP32 со встроенной камерой. Автор показывает базовый пример захвата изображения и его отображения на компьютере через веб-интерфейс.

**Основные моменты ролика:**

* Обзор модуля **ESP32-CAM** и его возможностей для проектов компьютерного зрения.
* Подключение платы к ПК через программатор с microUSB.
* Подготовка Arduino IDE: установка плат ESP32 и необходимых библиотек (WiFi, ESP WebServer, WebSockets, ArduinoJson, ESP32 Camera).
* Настройка камеры через файл `camera_config.h` (пины, разрешение кадра, формат JPEG, качество изображения).
* Подключение ESP32-CAM к локальной Wi-Fi сети и получение IP-адреса.
* Создание простого **веб-сервера** с HTML-страницей и кнопкой *Capture* для захвата кадра.
* Использование **WebSockets** для обмена данными между микроконтроллером и браузером.
* Реализация логики: при нажатии кнопки кадр фиксируется и отображается в браузере.
* Демонстрация работы: однократный захват кадра и модификация кода для стриминга видео.



### ESP32-CAM 02: microSD и SPIFFS

Во втором видео серии рассматриваются способы работы с памятью модуля **ESP32-CAM**. Автор показывает, как сохранять и считывать изображения с камеры на карту microSD и во внутреннюю файловую систему SPIFFS.

**Основные моменты ролика:**

* Обзор вариантов памяти в ESP32-CAM:

  * **microSD карта** (внешняя память, подходит для хранения большого количества изображений).
  * **SPIFFS** (встроенная файловая система во флеше ESP32).
* Подключение и инициализация microSD:

  * Использование библиотеки `SD_MMC.h`.
  * Проверка корректности монтирования карты памяти.
  * Создание и запись файлов (JPEG-кадров) на microSD.
* Работа со SPIFFS:

  * Подключение библиотеки `SPIFFS.h`.
  * Форматирование, монтирование и работа с файловой системой.
  * Запись и чтение файлов внутри флеш-памяти микроконтроллера.
* Сравнение microSD и SPIFFS:

  * microSD удобна для хранения больших объёмов данных,
  * SPIFFS — быстрый и простой вариант для небольших файлов и настроек.
* Демонстрация работы: сохранение изображений с камеры на microSD и в SPIFFS, чтение и проверка содержимого.



### ESP32-CAM 03: элементы управления

В третьем видео серии рассматривается, как создать веб-интерфейс для управления параметрами камеры ESP32-CAM. Автор показывает, как реализовать разные элементы управления (радиокнопки, ползунки и переключатели On/Off), которые позволяют изменять настройки изображения в реальном времени.

**Основные моменты ролика:**

* Использование встроенного веб-сервера ESP32-CAM для отображения HTML-страницы управления.
* Подключение к структуре данных сенсора через `esp_camera_sensor_get()` для изменения параметров камеры.
* Реализация трёх типов элементов управления:

  * **Радиокнопки** — выбор фильтров для изображения (например, негатив, красный оттенок и др.).
  * **Ползунки** — настройка параметров с диапазоном значений (например, яркость и контраст).
  * **Переключатели On/Off** — включение и отключение функций (например, баланс белого или отражение).
* Передача данных между веб-страницей и микроконтроллером с помощью **WebSockets** и JSON-сообщений.
* Логика синхронизации: изменения с веб-интерфейса применяются к камере, а камера отправляет обновлённое состояние обратно в браузер.
* Демонстрация работы: выбор фильтров, регулировка яркости и включение/выключение параметров отображаются сразу в итоговом кадре.



### ESP32-CAM 04: рисунок поверх изображения

В этом видео рассматривается, как работать с изображениями, полученными с камеры ESP32-CAM, и наносить на них графику и текст. Автор показывает принципы конвертации форматов изображений и использования специальных библиотек для рисования поверх кадра.

**Основные моменты ролика:**

* Получение кадра с камеры в формате **JPEG** и отправка его в браузер.
* Конвертация изображения в формат **RGB888**, позволяющий работать напрямую с пикселями.
* Структура RGB888: каждый пиксель описывается тремя байтами (R, G, B), что позволяет изменять цвет отдельных точек.
* Демонстрация низкоуровневого доступа к пикселям (закрашивание отдельных областей напрямую).
* Использование библиотеки **FB_GFX** для рисования:

  * прямоугольники, линии, буквы и текст;
  * работа с цветами через битовые комбинации.
* Создание собственных функций:

  * рисование окружности (через расчёт координат по синусу и косинусу),
  * затемнение участка изображения (понижение яркости в выбранном прямоугольнике).
* Конвертация изменённого кадра обратно в **JPEG** и передача на веб-страницу через WebSockets.
* Итог: возможность накладывать графику и текст на изображения с камеры ESP32-CAM в реальном времени.

* Итерация по пикселям выбранного участка и запись их в новый буфер.

### ESP32-CAM 08: сравнение изображений

В этом видео рассматривается, как сравнить два изображения на ESP32-CAM и использовать это для детекции движения или изменений в кадре.

**Основные моменты ролика:**

* Интерфейс содержит две кнопки:

  * **Set Main** — захват основного изображения для сравнения,
  * **Get Current** — получение текущего изображения для анализа.
* Оба изображения переводятся из **JPEG** в формат **RGB888** для работы с пиксельными данными.
* Алгоритм сравнения:

  * для каждого пикселя вычисляется разница по красной, зелёной и синей компонентам,
  * значения суммируются по всем пикселям,
  * дополнительно рассчитывается среднее значение.
* Полученные показатели выводятся в веб-интерфейсе и в последовательный порт.
* Демонстрация работы:

  * при статичной сцене разница минимальна,
  * при изменении (например, движении руки в кадре) значения резко возрастают, фиксируя факт движения.



### ESP32-CAM 09: детекция линии

В этом видео разбирается алгоритм детекции границ линии на изображении, полученном с камеры ESP32-CAM. Такой подход часто применяется в робототехнике, например в роботах, которые следуют по линии на полу.

**Основные моменты ролика:**

* Захват изображения с камеры в формате **JPEG** и передача его в браузер.
* Конвертация кадра из JPEG в **RGB888**, а затем в **градации серого** (чёрно-белое изображение).
* Реализация функции **jpegToGray()**, которая переводит каждый пиксель по формуле:
  `Gray = 0.114*Blue + 0.587*Green + 0.299*Red`.
* Анализ чёрно-белого изображения по заданным горизонтальным линиям (Y-координатам):

  * поиск резких перепадов значений пикселей (белый → чёрный и чёрный → белый),
  * определение левой и правой границ линии,
  * вычисление координаты центра.
* Реализация функции **findBorders()**, которая возвращает координаты X для найденных границ.
* Визуализация результата: рисование найденных линий и границ поверх изображения с помощью библиотеки **FB_GFX**.
* Демонстрация работы: камера успешно находит и отмечает границы линии на листе с наклеенной полосой.



### ESP32-CAM 10: определение цвета

В этом видео рассматривается алгоритм распознавания цвета на выделенном участке изображения с камеры ESP32-CAM.

**Основные моменты ролика:**

* Захват изображения с камеры и отображение его в браузере.
* Определение области (окошка) в центре кадра, в которой вычисляется цвет.
* Представление каждого пикселя как трёхмерного вектора (**R, G, B**), где значения варьируются от 0 до 255.
* Расчёт среднего значения компонент (R, G, B) на выделенной области для уменьшения ошибки (учёт освещённости, шумов и битых пикселей).
* Сравнение полученного «неизвестного» цвета с набором заранее измеренных эталонных цветов (красный, оранжевый, жёлтый, зелёный, голубой, фиолетовый, белый, чёрный и др.).
* Использование **евклидова расстояния** для поиска ближайшего цвета: чем меньше расстояние до эталона, тем выше вероятность совпадения.
* Реализация функций:

  * **colorDifference()** — вычисление расстояния между цветами,
  * **getColorName()** — выбор ближайшего цвета из базы,
  * **detectColor()** — усреднение по области и определение итогового цвета.
* Передача результата на веб-страницу через **WebSockets** и отображение названия цвета в реальном времени.
* Демонстрация работы: корректное определение разных цветов бумаги (красный, оранжевый, жёлтый, зелёный, голубой, фиолетовый, белый, чёрный).






### ESP32-CAM 11: HSV цветовой фильтр – Summary

В этом видео мы изучаем, как выделять определённые цвета на изображении, получаемом с модуля камеры ESP32-CAM, используя HSV цветовой формат.

Основные шаги и темы ролика:

1. **Подготовка микроконтроллера**

   * Код загружен на ESP32-CAM.
   * Микроконтроллер подключен к Wi-Fi, получен IP-адрес.
   * Возможность управления параметрами HSV через веб-страницу (подробно рассматривалось в видео №3 плейлиста).

2. **Выбор диапазона цвета**

   * Выделение красного цвета: задаются диапазоны оттенка, насыщенности и яркости.
   * Выделение зелёного цвета: изменяется диапазон оттенка, а диапазоны насыщенности и яркости остаются прежними.
   * Примечание: точный подбор диапазонов зависит от освещения и характеристик сцены.

3. **Преобразование изображения из RGB в HSV**

   * JPEG изображение сначала конвертируется в формат RGB888.
   * Затем каждый пиксель преобразуется в HSV:

     * **Hue (оттенок)** – определяет цвет.
     * **Saturation (насыщенность)** – интенсивность цвета.
     * **Value (яркость)** – светлоту цвета.
   * Компоненты HSV в коде нормализованы в диапазон 0–255 для удобства обработки.

4. **Алгоритм преобразования пикселя RGB → HSV**

   * Определяются минимальное и максимальное значение RGB-компонент.
   * Вычисляется дельта (разница между максимумом и минимумом).
   * Рассчитываются яркость, оттенок и насыщенность.
   * Пиксель преобразуется и сохраняется в HSV-буфер.

5. **Применение маски цвета**

   * Функция `applyMask` использует HSV-буфер для фильтрации цветов.
   * Пиксели, соответствующие заданному диапазону HSV, остаются цветными, остальные заменяются белым.
   * После обработки буферы освобождаются, результат конвертируется обратно в JPEG и отправляется на веб-страницу.

6. **Демонстрация результатов**

   * Выделение контуров объектов определённого цвета (например, красного отвёртка или зелёной полосы).
   * Обсуждается влияние диапазонов и шумов на результат.

В итоге видео показывает, как с помощью ESP32-CAM и HSV фильтра можно выделять определённые цвета на изображении, управлять параметрами через веб-интерфейс и применять маску для визуализации выбранного цвета.




### ESP32-CAM 12: операция свёртки

В этом видео мы рассматриваем, как применять операцию свёртки для обработки изображений с камеры ESP32-CAM.

Основные шаги и темы ролика:

1. **Подготовка микроконтроллера**

   * Код загружен на ESP32-CAM.
   * Микроконтроллер подключен к Wi-Fi, получен IP-адрес.
   * Веб-страница используется для отображения изображений и результатов обработки.

2. **Преобразование изображения в чёрно-белое**

   * Исходное цветное изображение конвертируется из JPEG в RGB888, а затем в чёрно-белое.
   * Для получения серого пикселя используется взвешенная сумма RGB-компонент:

     * Красный × 0.299
     * Зелёный × 0.587
     * Синий × 0.114
   * Чёрно-белое изображение используется как одноканальное для упрощения применения свёртки.

3. **Применение свёртки (convolution)**

   * Функция `convolution` принимает изображение, оператор (ядро свёртки) и размеры изображения.
   * Применяются разные операторы:

     * **Идентичное преобразование** – оставляет изображение практически без изменений.
     * **Размытие**, **повышение резкости**, **выделение вертикальных и горизонтальных границ**.
     * **Лаплас**, **Робертс**, **Собель**, **Превит** – для выделения границ.
   * Свёртка выполняется проходом по каждому пикселю изображения с умножением значений пикселей на соответствующие элементы ядра и суммированием результатов.
   * Для операторов с двумя компонентами (например, Робертс, Собель) вычисляется горизонтальная и вертикальная составляющая, после чего результат объединяется через квадратный корень суммы квадратов.

4. **Работа с результатами**

   * Результаты свёртки записываются в отдельный буфер и конвертируются обратно в JPEG для отображения на веб-странице.
   * Размер изображения после свёртки уменьшается на ширину/высоту, зависящую от размера ядра оператора.

5. **Демонстрация**

   * Показано применение разных операторов и визуализация эффекта на исходном изображении.
   * Объясняется влияние ядра на обработку, выделение границ и усиление резкости.

В итоге видео показывает, как с помощью ESP32-CAM и операции свёртки можно применять различные фильтры и алгоритмы обработки изображений, включая размытие, повышение резкости и выделение границ.



### ESP32-CAM 13: преобразование Хафа для окружностей

В этом видео показано, как детектировать окружности на изображении с камеры ESP32-CAM с помощью алгоритма преобразования Хафа.

Основные шаги и темы ролика:

1. **Подготовка микроконтроллера и изображения**

   * ESP32-CAM подключен к Wi-Fi, получен IP-адрес, видео и изображения доступны на веб-странице.
   * Захваченный кадр содержит объекты разного диаметра (например, монеты).

2. **Преобразование изображения**

   * Исходное изображение конвертируется в чёрно-белое (grayscale).
   * С помощью оператора Лапласа выделяются контуры объектов.
   * Для удаления шумов применяется функция `DeleteNoise`, которая зануляет одиночные пиксели и шумные участки.

3. **Алгоритм преобразования Хафа для окружностей**

   * Для каждого белого пикселя изображения с контурами на новом изображении («пространство Хафа») чертится окружность с заданным радиусом.
   * Если радиус совпадает с радиусом окружности на исходном изображении, в центре «розочки» накапливается максимальное значение яркости.
   * Таким образом определяется координата центров искомых окружностей.
   * Для точного выделения центров используется пороговое значение яркости и проверка расстояния между найденными точками, чтобы избежать дублирования центров.

4. **Работа с найденными окружностями**

   * Координаты центров окружностей сохраняются в массивы, а количество найденных окружностей выводится в последовательный порт.
   * На исходное изображение в формате RGB888 наносятся найденные окружности для визуализации.

5. **Демонстрация и проверка**

   * Алгоритм успешно находит окружности одинакового радиуса, игнорируя объекты другого размера.
   * Показано, как перемещение объектов на изображении не влияет на корректность детекции.

В итоге видео демонстрирует, как с помощью ESP32-CAM и преобразования Хафа можно эффективно находить окружности на изображениях, фильтруя шумы и визуализируя результаты.



### ESP32-CAM 14: преобразование Хафа для прямых линий

В этом видео показано, как выделять прямые линии на изображении с камеры ESP32-CAM с помощью алгоритма преобразования Хафа.

Основные шаги и темы ролика:

1. **Подготовка микроконтроллера и изображения**

   * ESP32-CAM подключен к Wi-Fi, получен IP-адрес, изображения доступны на веб-странице.
   * Захваченный кадр конвертируется в чёрно-белый формат для последующей обработки.

2. **Выделение контуров и шумоподавление**

   * С помощью свёртки и оператора Лапласа выделяются границы объектов.
   * Применяется фильтрация шумов: одиночные и изолированные пиксели зануляются.

3. **Преобразование Хафа для линий**

   * Для каждого белого пикселя изображения с контурами строятся линии под разными углами (от -90° до 90°).
   * Параметры каждой линии (угол θ и расстояние R до начала координат) откладываются в «пространство Хафа».
   * В ярких точках пространства Хафа накапливаются линии, соответствующие реальным контурам объектов.

4. **Фильтрация и объединение линий**

   * Линии, лежащие практически на одной траектории, объединяются в одну.
   * Проверяется евклидово расстояние между линиями, чтобы избежать дублирования.

5. **Визуализация результата**

   * Координаты отфильтрованных линий преобразуются обратно на исходное изображение.
   * На изображении строятся линии по контурам объектов (например, зубочисток), отображая результаты работы алгоритма.

В результате видео демонстрирует, как с помощью ESP32-CAM и преобразования Хафа можно эффективно детектировать и визуализировать прямые линии на изображениях, фильтруя шум и объединяя совпадающие линии.



### ESP32-CAM 15: TensorFlow Lite — классификация изображений

В этом видео мы показываем, как реализовать классификацию изображений на микроконтроллере **ESP32-CAM** с использованием **TensorFlow Lite**. Основные шаги включают:

1. **Подготовка датасета**

   * Захват изображений объектов с помощью ESP32-CAM.
   * Сохранение изображений на MicroSD-карте.
   * Организация изображений по категориям (например, матрёшка, мышь, гаечный ключ) для обучения нейронной сети.

2. **Создание и обучение сверточной нейронной сети (CNN)**

   * Используется Python и Jupyter Notebook для подготовки модели.
   * Применяется разделение данных на тренировочные и проверочные (10% для проверки).
   * Настройка **аугментации изображений** для повышения устойчивости модели к различным условиям съемки.
   * Построение структуры CNN с несколькими сверточными слоями, полносвязным слоем и функцией softmax для классификации.
   * Обучение модели на 150 эпох с контролем точности и уменьшением ошибки.

3. **Конвертация модели в TensorFlow Lite (TFLite)**

   * Исходная модель H5 слишком велика для ESP32-CAM (~12 МБ).
   * Преобразование в **легковесный формат TFLite с 8-битной квантовкой** для работы на микроконтроллере.
   * Подготовка representative dataset для конвертации.
   * Проверка точности облегчённой модели (около 83%).

4. **Загрузка модели на ESP32-CAM и интеграция**

   * Использование Arduino IDE и библиотеки TensorFlow Lite для ESP32.
   * Инициализация интерпретатора модели, выделение памяти под промежуточные вычисления.
   * Настройка веб-интерфейса для получения снимков и отображения результатов классификации.
   * Обработка входного изображения: уменьшение размера, преобразование пикселей в диапазон [-128, 127], передача на вход модели.
   * Вывод вероятностей для каждого класса на веб-странице в реальном времени.

5. **Демонстрация работы модели**

   * Классификация различных объектов с камеры: матрёшка, мышь, гаечный ключ.
   * Отображение распределения вероятностей для каждого класса.
   * Обработка ошибок и корректная работа модели на реальных изображениях.

**Результат:** ESP32-CAM успешно классифицирует объекты в реальном времени, используя обученную и оптимизированную CNN в формате TensorFlow Lite. Веб-интерфейс позволяет визуализировать результаты и получать снимки с камеры.
